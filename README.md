🛍️ ZI-Store
A modern, feature-rich e-commerce mobile application built with Flutter, designed to provide a seamless shopping experience for clothing and apparel with clean navigation and robust state management.

📱 About The Project
ZI-Store is a specialized e-commerce mobile application developed as a comprehensive software project. It features a curated product catalog, detailed item views, smooth category filtering, a dynamic cart and checkout workflow, and a polished user interface complete with custom curved navigation layouts.

✨ Key Features
Dynamic Product Catalog: Browse a wide variety of clothing items fetched seamlessly from public API endpoints.

Custom Navigation: Implements an intuitive, custom-designed curved navigation bar for a fluid user experience.

State Management: Efficient and predictable UI state updates throughout the user journey.

Detailed Product Views: View comprehensive product details, sizing options, descriptions, and pricing.

Shopping Cart & Checkout Flow: Easily manage items in the cart, adjust quantities, and proceed through a streamlined checkout experience.

Responsive Layout: Optimized to look and feel exceptional across various mobile screen dimensions.

🛠️ Tech Stack & Architecture
Framework: Flutter (Cross-platform mobile development)

Language: Dart

Architecture: Component-driven, scalable folder structure ensuring separation of concerns.

APIs: RESTful endpoints integration for dynamic data loading.

🚀 Getting Started
To get a local copy up and running, follow these simple steps.

Prerequisites
Ensure you have the Flutter SDK installed on your machine.

An active internet connection to fetch packages and API data.

An emulator (Android/iOS) or a physical device connected.

Installation
Clone the repository

Bash
git clone https://github.com/Ziad-Gabriel/ZI-Store.git
Navigate to the project directory

Bash
cd ZI-Store
Install dependencies

Bash
flutter pub get
Run the application

Bash
flutter run
